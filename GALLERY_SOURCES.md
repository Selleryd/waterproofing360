## Verification limits

The homepage link hrefs and title associations were retrieved from the public source page, not inferred from gallery IDs. The external album fetches returned a cache miss through web retrieval; this does not prove that the galleries are unavailable in a normal browser. This environment also restricted Chromium URL navigation. Tests verify each unchanged href, distinct album ID, isolated new-tab creation, navigation route, and thumbnail placement. They do **not** verify the contents of or network access to each external album.

## Photo provenance

The seven local `assets/project-*.webp` files are direct crops of the original service thumbnails shown in the user's uploaded screenshot. No AI generation, content replacement, or invented project label was applied. A small downsample produced 176 × 176 pixel images. The maximum display size is 124 CSS pixels on gallery cards; homepage cards use smaller previews. Direct download of the original CDN files failed, so these should not be described as recovered original-resolution photo assets.

Crop coordinates, exact public source thumbnail URLs, and original mappings are retained in `content/galleries.json`. Full gallery photographs were not downloaded or republished. Architectural hero images and the 3D illustration remain separate from these documentary thumbnails.
